MODERNIZATION EVIDENCETEST 2 / 2026

A newer runtime, with the same banking rules.

This isolated experiment upgrades a copied legacy banking application from Java 8 build settings to Java 21. Its public account behaviour stays deliberately unchanged.

Functional result
Withdrawals still reduce a balance. Invalid withdrawals still throw IllegalArgumentException. The two characterization tests pass before and after the build migration.

What changed

The Maven release contract now targets Java 21. Compiler and test plugins are configured explicitly for a current JDK.

What did not

Account.java and AccountTest.java are untouched. No banking feature, public API, or data model changed.

Why this shape

Compatibility is proven first. This version migration does not hide a product rewrite behind new language settings.

Review boundary

Only test2/ changes. The shared template/ and earlier test1/ remain untouched.

A Java 21-ready build, not a speculative rewrite.
